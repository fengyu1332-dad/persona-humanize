# 英文 AI 味特征词库与替换建议

用于英文文本的 Step 2 诊断与 Step 4 改写。英文的 AI 味来源与中文不同，集中在「标志性大词 + 过渡词滥用 + 陈词滥调 + 拒绝口语化」。

---

## 1. AI 标志性大词（2024-2026 高频暴露点）

这些词在 AI 生成的英文里出现频率极高，一出现即暴露机器感。

| AI 味 | 真人替代 |
|---|---|
| delve into | look into, dig into, get into |
| dive into / deep dive | jump in, take a look |
| unleash | release, let out, use |
| embark on | start, begin |
| navigate | handle, deal with, get through |
| leverage | use, tap into, make the most of |
| foster | build, encourage, grow |
| streamline | simplify, speed up |
| empower | help, enable, give power to |
| harness | use, tap |
| utilize | use |
| underscore | show, stress, underline |
| highlight | point out, flag |
| showcase | show off, display |
| revolutionize | change, shake up |

## 2. 过渡词与连接词滥用

AI 爱在每个句首塞一个过渡词，导致每段读起来像幻灯片要点。

| AI 味 | 真人替代 |
|---|---|
| Moreover / Furthermore / Additionally / In addition | Also, Plus, And, What's more, On top of that |
| However / Nevertheless / Nonetheless | But, Still, That said, Though |
| Therefore / Consequently / Thus / Hence | So, That's why, As a result |
| In conclusion / To sum up / In summary | 删掉，或 "Bottom line", "Anyway" |
| It is important to note that / It is worth mentioning that | 删掉，直接写重点；或 "Keep in mind", "Note" |
| In today's fast-paced world / In the ever-evolving landscape | 删掉，直接进正题 |
| When it comes to / In terms of | 删掉，或 "As for" |
| With regard to / Regarding | About, On |

以上词组能删则删，能换成具体说法就换具体说法。连续三个以上即判定为 AI 味重。

## 4. 语法层面的「机器感」

- **拒绝使用 contractions**：AI 常写 "do not / cannot / it is / I am"，真人写 "don't / can't / it's / I'm"。正式文体外一律收缩。
- **被动语态泛滥**："It can be seen that / It has been found that / measures should be taken" → 换成主动语态 "You can see / We found / we need to"。
- **名词化（nominalization）**："The implementation of the plan was successful" → "We rolled out the plan and it worked"。
- **每句都是完整规范句**：真人会有 sentence fragments（"Not bad." "Again."）、run-on、短句。
- **过度使用 em-dash 和括号补充**：AI 爱用 "— that is, ... —" 和 "(e.g., ...)" 自我解释；真人直接说。

## 5. 结构上的「AI 感」

- **完美的五段式 / 三段式**：intro + 三点 body + conclusion，每段长度均匀。
- **每段首句是 topic sentence**，末尾句是 mini-conclusion——教科书式结构。
- **bullet point 强迫症**：把流畅的话拆成整齐的要点。
- **强行平衡**："On the one hand... on the other hand..." 永远两面都说。
- **结尾必升华**："As we move forward, ..." / "In an increasingly interconnected world, ..."。

## 6. 英文「人味」素材库

按画像取用：

- **Contractions**：don't, can't, it's, I'm, you're, we've, ain't（按人物设定）
- **Filler & discourse markers**：well, you know, I mean, honestly, to be fair, look, so, right?
- **口语短语**：a ton of, kind of, sort of, pretty much, a bit, no big deal, what a mess, fair enough
- **Idioms（按需）**：cut to the chase, get the ball rolling, on the same page, in the weeds, drop the ball, bite the bullet, the bottom line
- **短句与 fragment**："Fine." "Not really." "Who knows." "So that happened."
- **情绪表达**：to be honest, I'm not gonna lie, that drove me nuts, love it, hate it, honestly who cares
- **具体化钩子**：put in a real date / name / number / place；"Last Tuesday", "my boss Sarah", "the third line of the error log"

## 快速改写检查表（英文）

改写完逐条过：
1. 还有没有 delve / leverage / foster / Moreover / In conclusion？→ 全换。
2. 有没有 contractions？→ 没有就补（正式文体除外）。
3. 被动语态和名词化多不多？→ 改主动、改动词。
4. 是不是完美五段式、段落等长？→ 打乱节奏。
5. 有没有 filler、idiom、短句 fragment？→ 没有就加。
6. 有没有具体的人名/日期/数字/场景？→ 没有就把抽象词落地。
7. 结尾是不是还在 "As we move forward" 升华？→ 改成一句话收尾或戛然而止。
8. 读起来像不像某个 native speaker 在打字，而不是 GPT 在生成？→ 不像就继续调。
