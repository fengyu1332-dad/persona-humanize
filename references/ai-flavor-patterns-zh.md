# 中文 AI 味特征词库与替换建议

用于 Step 2 诊断与 Step 4 改写。按「特征类别 → 典型 AI 味 → 真人替代」组织。改写时逐类排查，不是逐词替换。

---

## 1. 逻辑连接词脚手架（最高频暴露点）

AI 喜欢用显式连接词把逻辑「钉死」，真人靠内容自然推进，很少这么铺陈。

| AI 味 | 问题 | 真人替代 |
|---|---|---|
| 首先 / 其次 / 再次 / 最后 | 列点强迫症，机械 | 直接写；或用「先说第一件」「还有」「另外」 |
| 综上所述 / 总而言之 / 总的来说 | 强行总结 | 删掉，或「所以」「说白了」 |
| 值得注意的是 / 需要强调的是 / 值得一提的是 | 无信息量的提示 | 删掉，直接写重点 |
| 不难发现 / 由此可见 / 不言而喻 / 显而易见 | 装客观、假推理 | 删掉，或「你看」「明显」 |
| 一方面……另一方面…… | 对称强迫 | 拆开，用「但」「其实」 |
| 不仅……而且…… / 既……又…… / 无论……都…… | 排比堆砌 | 砍掉一半，只留一层 |
| 随着……的发展 / 在……的背景下 / 对于……而言 | 万能开头模板 | 直接进正题 |
| 从……的角度来看 / 就……而言 | 学术腔 | 「我觉得」「说白了」 |

## 2. 互联网黑话与万能动词

AI 生成的中文爱堆「大厂黑话」，显得空、虚、假大空。

| AI 味 | 真人替代 |
|---|---|
| 赋能 | 帮、让……能做、给了……能力 |
| 抓手 | 办法、突破口、切入点 |
| 闭环 | 跑通、做成、完整流程 |
| 沉淀 | 积累、总结、留下 |
| 底层逻辑 | 根本原因、本质、道理 |
| 颗粒度 | 细、细节、程度 |
| 打造 / 构建 / 搭建 | 做、写、搭、搞 |
| 推动 / 助力 / 促进 | 帮、让、推一把 |
| 致力于 / 旨在 / 力求 | 想、打算、奔着 |
| 探索 / 挖掘 | 找、试、看 |
| 彰显 / 诠释 / 诠释 / 凝练 | 表现、说明、体现 |
| 生态 / 矩阵 / 链路 / 场域 | 具体的人/事/物 |
| 提供有力支撑 | 帮上忙、顶得上 |
| 注入新的活力 | 让它活起来了、热闹了 |
| 翻开崭新的一页 | （删掉，具体写发生了什么） |
| 具有重要的现实意义 / 具有深远影响 | 真的很重要 / 影响不小（+ 具体） |
| 可以预见 / 未来可期 | 后面会更好（或删掉） |

## 3. 抽象名词堆砌与「万能套话」

AI 爱用抽象、宏大、无具体所指的词。

- 「高质量发展、可持续发展、全链路、一站式、全方位、多层次、多维度、系统性、战略性」——能删就删，换成具体所指。
- 「提升、优化、完善、强化」后面不接具体对象，就是空话；必须落到「提升了什么、怎么提升的」。
- 「解决方案、价值主张、核心诉求、用户心智」这类包装词，换成大白话。

**原则**：凡是无法回答「具体指什么」的词，一律替换或删除。

## 4. 结构上的「AI 感」（比用词更隐蔽）

- **段落字数趋同**：每段都 3-5 行，是模板感；真人段落长短随意。
- **每段「总-分-总」**：开头下定义、中间举例、结尾升华——这是议论文机器。
- **强行三点式**：「主要有三个原因」「体现为三个方面」——真人想到哪写到哪，不凑数。
- **对称小标题**：两个四个字的对仗小标题排成一行。
- **每段结尾都要抖机灵/升华**：真人会说一半就停。

## 5. 情绪与态度的缺失（AI 味的根源）

- AI 无立场、无偏爱、无情绪波动，永远「客观中立」「辩证看问题」。真人一定会**站边、下判断、带情绪**。
- 补救：加入「说实话、其实、我就直说了、说真的、这玩意儿、太坑了、真香、无语、服了」等主观情绪词。
- AI 结尾爱「升华 + 展望未来」，真人结尾常是「一个具体动作、一句吐槽、一个问句、戛然而止」。

## 6. 中文口语化「人味」素材库

按需从画像决定用多少：

- **语气词**：嘛、吧、啦、呢、啊、哦、哈、呗、喽
- **口头禅/缓冲**：说真的、讲道理、你别说、就、挺、有点、反正、说白了、差不多、那什么
- **情绪词**：真香、无语、服了、绝了、离谱、太顶了、心态崩了、上头
- **网络语（按年龄慎用）**：yyds、绝绝子、破防、内卷、躺平、摆烂、上分、懂王
- **具体化钩子**：「就上礼拜三」「我那个朋友」「第三行代码」「办公室里那个」

## 快速改写检查表（中文）

改写完逐条过：
1. 还有没有「首先/其次/综上所述/值得注意的是」这类脚手架？→ 全删。
2. 还有没有「赋能/抓手/闭环/底层逻辑」这类黑话？→ 换大白话。
3. 段落长短是不是还整整齐齐？→ 打乱。
4. 有没有作者自己的立场和情绪？→ 没有就加。
5. 有没有具体的人/事/数字/场景？→ 没有就把抽象词落地。
6. 结尾是不是还在强行升华？→ 改成一个具体动作或戛然而止。
7. 读起来像不像「某个人在说话」，而不是「一篇文章在陈述」？→ 不像就继续调。
