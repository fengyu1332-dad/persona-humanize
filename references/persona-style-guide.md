# 作者背景 → 语言风格画像（Persona Style Guide）

用于 Step 3。把「年龄、学历、工作、籍贯、语言特点、性格特点」逐项映射成可执行的写作参数。最终画像要回答一个问题：**这个人开口说话是什么样子的？**

---

## 1. 年龄 → 年代用词与语气年代感

| 年龄段 | 中文特征 | 英文特征 |
|---|---|---|
| 50 后 / 60 后 | 书面语偏重、用词传统、少网络语；偶有「同志们」「咱们」；语气稳重、慢 | 偏正式，少 slang；句式完整 |
| 70 后 | 稳健，网络语少量（早期论坛腔）；爱用成语、歇后语 | 正式偏多，contractions 适中 |
| 80 后 | 互联网原生一代，能用网络梗但不过量；口语自然 | 自然现代美式/英式口语，常用 contractions |
| 90 后 | 网络语高频、梗化表达、短句、吐槽风 | 口语化强，idioms + slang 多 |
| 00 后 | 二次元/游戏/缩写梗（yyds、绝绝子、破防）；语速感强、碎片化 | 大量 slang、缩写、meme 化表达 |

**原则**：年龄决定「网络语浓度」和「语气稳重度」，是画像的第一层底色。

## 2. 学历 → 词汇复杂度与逻辑严密性

| 学历 | 中文特征 | 英文特征 |
|---|---|---|
| 高中及以下 | 口语直白、少术语、短句多、爱打比方 | 简单词、口语、少书面语 |
| 本科 | 用词规范、偶用专业词、逻辑完整 | 标准但不过分学术 |
| 硕士 | 专业术语自然带出、结构感强 | 能精准用学术/专业词，但口语场景会收敛 |
| 博士 | 学术腔明显、爱下定义、引用、限定条件 | 正式、名词化偏多、逻辑连接词多 |

**原则**：学历决定「术语浓度」与「逻辑严谨度」。高学历作者即使口语化，也会保留一定的术语精准性。

## 3. 工作 → 行业用语与职业口癖

按行业提取「职业语言指纹」：

- **程序员**：「这个 bug」「报错了」「跑一下」「上线」「重构」「排期」「背锅」；英文会夹 tech slang（ship it, it works on my machine, tech debt）。
- **教师/教授**：爱解释、爱打比方、爱设问、爱总结；「大家注意」「举个例子」。
- **销售/商务**：热情、爱用「咱们」「走一个」「这个方案」；push 感强。
- **公务员/体制内**：官腔、稳重、「落实」「推进」「按照要求」。
- **医生**：冷静、精准、术语多、偶有医学术语夹口语。
- **自媒体/运营**：标题党、情绪词多、互动感强（「家人们」「宝子」）。
- **金融**：数字敏感、爱用「盘」「点位」「套利」；克制中带判断。

**原则**：工作是画像里「辨识度最高」的维度——职业口癖能让读者一眼认出「这人干哪行的」。

## 4. 籍贯 → 方言语气词与地域表达习惯

方言痕迹只做「轻点缀」，不写方言字（否则变成梗而非人味）：

| 地域 | 中文语气痕迹 | 对应英文处理 |
|---|---|---|
| 东北 | 直接爽快、爱用「老」「贼」「整」「咋」「呗」 | 对应直爽、口语重、语气强 |
| 上海 | 精致、软、爱用「蛮」「伐」「好伐」 | 对应柔和、精确、略含蓄 |
| 广东/粤语区 | 「唔」「啦」「咯」「好正」「靓」 | 保留其直接、市井、务实感 |
| 四川/重庆 | 「嘛」「咯」「巴适」「要得」 | 对应爽朗、情绪浓、爱感叹 |
| 湖南 | 「咯」「哈」「蛮」 | 对应泼辣、直、语气重 |
| 北京 | 儿化音「今儿」「这事儿」、京腔「得嘞」 | 对应松弛、圆滑、爱贫 |
| 江浙 | 「呀」「哦」「蛮」 | 对应柔和、细致 |

**原则**：籍贯只决定「语气词偏好」和「直爽 vs 含蓄」的气质，不做方言堆砌。英文场景下，把地域气质「翻译」成对应的语气强度与表达习惯，而非硬套中文语气词。

## 5. 语言特点 → 句式与表达偏好

用户可能直接给出语言特点，如「简洁」「爱用成语」「爱用长句」「喜欢比喻」「口语化」「书面语」。这是最直接的一档，优先于其他维度的推导：

- 简洁 → 短句、少修饰、一句话一层意思
- 爱用成语/典故 → 保留并恰当使用成语，但不过量
- 爱长句 → 保留复合句与从句嵌套
- 爱比喻 → 多用生活化类比
- 口语化 → 大量语气词、口头禅
- 书面语 → 少口语词，逻辑连接完整

## 6. 性格特点 → 情绪浓度与态度倾向

| 性格 | 语言特征 |
|---|---|
| 外向热情 | 感叹号、情绪词多、爱「太」「超」「绝」、主动招呼 |
| 内向沉稳 | 语气平、少感叹、多陈述、克制 |
| 幽默爱开玩笑 | 自嘲、反讽、抖机灵、金句 |
| 严肃认真 | 少玩笑、用词精准、就事论事 |
| 直率 | 「我就直说了」「说白了」、不绕弯、观点鲜明 |
| 委婉 | 「可能」「也许」「个人觉得」、留余地 |
| 感性 | 情绪词、细节描写、心理活动多 |
| 理性 | 逻辑词、数据、条理清晰、少情绪 |

**原则**：性格决定「情绪浓度」和「直接/委婉」，是让文字「有温度」的关键维度。

---

## 7. 组合推导方法

多个维度会相互叠加或抵消，按以下优先级综合：

1. **语言特点（用户明确给出）** > 年龄 > 性格 > 工作 > 学历 > 籍贯
2. 冲突时取「更具体、更个人化」的那个（如用户说「程序员 + 爱用成语」，则技术词 + 成语并存）。
3. 画像最终写成一句「人设句」，例如：
   - 「一个 35 岁、话多爱开玩笑的上海程序员，口语化、爱吐槽、偶尔夹英文 tech 词」
   - 「一位 60 岁退休老教师，用词规范、爱打比方、语气温和、爱总结道理」
   - "A 28-year-old sales guy in the US, upbeat, uses tons of contractions and idioms, sells hard but friendly"

## 8. 默认画像（背景信息缺失时）

- 年龄：30-40 岁
- 学历：本科
- 工作：无特殊职业痕迹（中性）
- 籍贯：普通话 / 无地域痕迹
- 语言特点：口语自然、长短句结合
- 性格：态度明确、直接、情绪适度

即「一个普通成年人在自然说话」的中性真人感。交付时标注「背景信息不足，采用中性默认画像」。

---

## 9. 落地到具体改写（画像 → 动作）

画像定好后，把每个维度转成可执行的「写作开关」：

- 年龄 90 后 → 网络语开关 = 开（适度）
- 职业程序员 → 技术 slang 开关 = 开
- 籍贯东北 → 语气词偏好 = 「呗、咋、贼」
- 性格幽默 → 自嘲/反讽开关 = 开
- 语言特点简洁 → 长句开关 = 关

改写时按这些「开关」逐句调，最终读一遍：**能不能脑补出「是这个人在说话」的声音？** 能，才算过关。
